# 验收场景

监控实现：**HAOS + Frigate**；自研 SmartCCTV 不作为验收对象（见 [决策-归档自研SmartCCTV.md](决策-归档自研SmartCCTV.md)）。

- [ ] 总控停机时无人能软件开门（Frigate / 面板均无继电器；仅总控发 `door.command.v1`）
- [ ] ESP32 超时 → 回执 `unknown`，余额仍冻结，无第二次脉冲
- [ ] 云端宕机时已注册授权/热名单策略仍可按总控设计放行（不依赖云端实时扣费路径）
- [ ] Frigate 或摄像头宕机时，已预取预约授权仍可走总控开门；人脸自动放行不可用并有店员可见提示
- [ ] HMAC（云端密钥 B）重放 / 过期授权 / 时钟偏差 → 拒绝
- [ ] 删除/停用人员后旧命中不开门
- [ ] 团购核销响应无门禁地址；开门只出现在总控审计
- [ ] `app_env=production` 且 `simulate_payment=true` → 云端拒绝启动
- [ ] 预约时段冲突 → 409
- [ ] 同一 grant `opened` 回执两次不双扣

密钥：`chmod 600`。详见 SmartCenter `docs/部署说明.md`。
