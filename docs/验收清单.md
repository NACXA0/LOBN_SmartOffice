# 验收场景

- [ ] 总控停机时 SmartCCTV 无法开门（无继电器调用）
- [ ] ESP32 超时 → 回执 `unknown`，余额仍冻结，无第二次脉冲
- [ ] 云端宕机时已注册人脸仍可开（热名单在总控内存）
- [ ] 监控宕机时已预取预约授权仍可开
- [ ] HMAC 重放 / 过期授权 / 时钟偏差 → 拒绝
- [ ] 删除/停用人员后旧命中不开门
- [ ] 团购核销响应无门禁地址；开门只出现在总控审计
- [ ] `app_env=production` 且 `simulate_payment=true` → 云端拒绝启动
- [ ] 预约时段冲突 → 409
- [ ] 同一 grant `opened` 回执两次不双扣

密钥：`chmod 600`；监控配置无 `open_url` 执行意义。详见 SmartCenter `docs/部署说明.md`。
