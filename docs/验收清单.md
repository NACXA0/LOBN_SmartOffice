# 验收场景（HAOS 四 App）

依据：[架构-HAOS四App.md](架构-HAOS四App.md) · 部署：[部署体系.md](部署体系.md)。自研 SmartCCTV **不验收**。

## 保命层

- [ ] 停掉 **SmartCenter Add-on** 后，店员/授权类保命路径仍能经 HA→`home/<node>/door/command`→ESPHome 开门
- [ ] `lobn_office` 适配器 `mqtt`：小程序开门队列 → `home/<gate|inner node>/door/command` → ESPHome；云端 consume/ack 仍通
- [ ] HA `input_button` 大门/里门（`packages/door_mqtt.yaml`）不经云端即可开门
- [ ] 停掉 HA / Mosquitto 后，软件开门不可用；物理钥匙/并联按钮仍可用
- [ ] ESPHome 超时或离线 → 不连发脉冲；云端不误扣（unknown/失败语义）
- [ ] 过期或重复 `command_id` 的 `business/access/grant` **不**脉冲（`packages/face_grant_mqtt.yaml`）

## RFID 资产防盗（仅 SmartCenter）

依据：[资产防盗-RFID.md](资产防盗-RFID.md)。

- [ ] HA 编辑白名单 → retained `home/<room>/rfid/allowlist` → ESP 缓存 rev 更新
- [ ] 未授权标签 → 板载警号响 + `home/<room>/rfid/event` `allowed=false` → HA 通知
- [ ] 授权标签 → 不响警号 + event `allowed=true`
- [ ] 断 HA / Wi‑Fi 短时：ESP 仍按最后名单比对并拉警号
- [ ] 停 Add-on / 停 FireClassroom：防盗链路不受影响
- [ ] 无 FireClassroom API / 小程序参与白名单或告警

## 感知与刷脸

- [ ] Frigate 宕机：刷脸自动开门停；保命开门仍可用；店员可见提示
- [ ] Frigate **Face Recognition 关闭**；`config.yml` 无业务门禁规则
- [ ] 摄像头对 go2rtc 连接数 ≤2（无直连旁路）
- [ ] 门口 zone `person` → Add-on 比对 → `business/access/grant` → 门开；审计有相似度/`user_id`（无现场图）
- [ ] 同人 30s 冷却、多人同框拒开、多帧不一致拒开
- [ ] `accepted` 门口前 3 次达标 → `verified`；连续 3 次低于验证线 → `pending` 需重采
- [ ] 云端停用学生后本地向量停用，旧 grant/冷却不能再开
- [ ] 红外/灰度画面跳过识别

## SmartCenter 工作台（Ingress）

依据：[人脸-SmartCenter-Add-on.md](人脸-SmartCenter-Add-on.md)。

- [ ] 无 Add-on 自建登录页；HA 管理员 Ingress 即可进
- [ ] 四页可用：概览 / 采集 / 人脸库 / 审计
- [ ] 采集：搜索选人 + 开始后自动送帧；**无**相册上传入口
- [ ] 人脸库：启停 Switch、删除二次确认、详情合格帧、补采跳转采集
- [ ] 概览：`/api/stats` 状态分布与待重采队列可见
- [ ] `/healthz` 含 store 计数；日志目录有滚动文件
- [ ] 维护策略生效（审计行数/年龄上限；取消会话不留半成品帧）

## 云端与安全

- [ ] 密钥 B / 中继 token 重放 / 错误 → 拒绝
- [ ] 小程序人脸会话帧经云端中继，云端**无**长期照片/向量
- [ ] 团购核销响应无门禁地址；开门只出现在店内审计
- [ ] `app_env=production` 且 `simulate_payment=true` → 云端拒绝启动
- [ ] 预约冲突 → 409；同一 grant 成功回执两次不双扣

## 铁律抽查

- [ ] HA 自动化内无排班 SQL / 无相似度算法
- [ ] Frigate `config.yml` 无人脸开门规则
- [ ] 无 App 间私有 HTTP 发开门指令（仅 MQTT command + 查询型 REST/go2rtc）
- [ ] Add-on `/data` 有在线备份与容量裁剪；备份不进 git/云对象存储
- [ ] HA 零智能 / Frigate 零业务 / 跨 App 只走 MQTT（见铁律）
