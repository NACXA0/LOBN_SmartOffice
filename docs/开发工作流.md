# 开发工作流（本机优先）

> 原则：**日常开发在本机**；店内 HAOS 只做生产安装与终验。  
> 对接现网：[对接已有HAOS.md](对接已有HAOS.md) · 人脸细节：[人脸-SmartCenter-Add-on.md](人脸-SmartCenter-Add-on.md)

---

## 1. 两套东西不要混

| 对象 | 目录 | 本机命令 | 说明 |
|------|------|----------|------|
| **SmartCenter Add-on** | `SmartCenter/addon/` | `./START.sh all` / `addon*` | 人脸工作台 + API；独立 FastAPI，不进 HA 进程 |
| **本机 HA** | `SmartCenter/config/` | 一键里顺带起，或 `./START.sh dev` | 测 packages / `lobn_office`；**无** Coral/真 Frigate |
| **云端** | `LOBN_FireClassroom/` | 该仓 `./START.sh` | 小程序中继、管理端（平台端/门店端）；文档 `LOBN_FireClassroom/docs/`；与店内 MQTT 解耦 |

店内 HAOS / Frigate / 真门 = **生产与终验**，不是热重载目标。

---

## 2. 推荐：一键开发（热更新）

```bash
cd SmartCenter
./START.sh repair --yes          # 首次：本机 HA 依赖
./START.sh addon-repair          # 首次：Add-on Python 依赖
./START.sh all                   # 或菜单「一键开发」
```

同生命周期拉起（**关终端 / Ctrl+C = 全停**）：

| 进程 | 地址 | 热更 |
|------|------|------|
| Vite 工作台 | http://127.0.0.1:5173/ | 改 `addon/web/src` → **HMR** |
| Add-on API | http://127.0.0.1:8080/ | 改 `addon/app/*.py` → **uvicorn --reload** |
| 本机 HA | http://127.0.0.1:8123/ | 改 `config/` 后按 HA 习惯重载 |

浏览器主看 **:5173**（开发）；生产 Ingress 吃的是构建产物 `addon/app/webui/`。

发版前：

```bash
./START.sh addon-ui-build    # → app/webui/
./START.sh addon-test        # pytest
```

## 3. 按改动选入口

| 改什么 | 命令 | 备注 |
|--------|------|------|
| UI / 工作台 | `./START.sh all` 或 `addon-ui`（需后端已起） | 勿只改 `app/webui` 手改构建产物 |
| 会话 / 比对 / 库 API | `all` 或 `addon-api` | 默认 `MQTT_HOST=off` |
| `face_grant_mqtt` / `door_mqtt` | 本机 HA | 可选本机 Mosquitto 验 grant |
| 小程序人脸中继 | FireClassroom `./START.sh` + Add-on | 配 `LOBN_SMARTCENTER_*` |
| 真门口 E2E | 店内 HAOS | 见 [对接已有HAOS.md](对接已有HAOS.md) `env.lan`（验完关掉） |

## 4. Add-on 工作台页（开发时对照）

无自建登录 / 无 RBAC：Ingress 或 Vite 直开即管理员。

| 路由（Hash） | 职责 |
|--------------|------|
| `#/overview` | 统计概览、待重采、运行时 |
| `#/capture` | 搜索选人 + 自动质检采集 |
| `#/gallery` | 人脸库管理 |
| `#/audit` | 开门流水 + 链路 |

源码：`SmartCenter/addon/web/` · 构建：`./START.sh addon-ui-build`。

## 6. 与生产差异（心智模型）

| | 本机开发 | 店内 HAOS |
|--|----------|-----------|
| 鉴权 | `SMARTCENTER_DEV_AUTH` 可跳过 Ingress | HA Ingress 已登录 |
| MQTT | 默认 off | Supervisor 注入 Mosquitto |
| 摄像头 | 笔记本 USB / 无门口事件 | Frigate + go2rtc |
| 前端 | Vite HMR | Add-on 内静态 `webui`（Docker 构建） |
| 嵌入模型 | 常 `mock` | 生产 `onnx` |
