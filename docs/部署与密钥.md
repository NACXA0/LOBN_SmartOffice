# 部署与密钥

监控已改为 **HAOS + Frigate 插件**；自研 SmartCCTV 准备归档，见 [决策-归档自研SmartCCTV.md](决策-归档自研SmartCCTV.md)。

## 现网主密钥

| 密钥 | 持有方 | 用途 |
|------|--------|------|
| B `cloud_hmac` | 云端 + 本店总控 | 总控拉授权 / 回执 / 人脸 / 打印 / 告警；请求须带 `X-Lobn-Store-Id` |
| ESP Bearer `esp_token` | 总控 + ESP32 | 门命令与 sense |

多店：每店一份 SmartCenter（HAOS）。HA 配置填本店 `store_id` / `room_id` 与该店 HMAC（门店档案可写店级密钥，空则用云端全局 `hmac_cloud_secret`）。两店不可共用同一 pending 拉取身份。

管理后台：配置 `admin_phones`；店长/运维在「店员角色」按手机号许可；生产用小程序「店员登录」扫码（仅未绑定时取手机号）。

学员 JWT 与店员角色 JWT 不混用。

## 云端零入站

办公室总控主动 HTTPS 访问云端；不对办公室开入站端口。

- 公网：`https://fireclassroom.aleedu.com`（Caddy：`LOBN_FireClassroom/deploy/Caddyfile.public`）
- 总控 `cloud_base_url`：同上；`cloud_hmac_secret` 与本店密钥一致，并配置 `store_id`
- 内网名：`smartcenter.lobn` / `fireclassroom.lobn`（`Caddyfile.lan`）；`cctv.lobn` 仅为旧自研监控别名，归档后可去掉
