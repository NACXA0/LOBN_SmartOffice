# 部署与密钥

## 三钥分离（0600）

| 密钥 | 持有方 | 用途 |
|------|--------|------|
| A `cctv_event_hmac` | 监控 + 总控 | 监控 → 总控事件 |
| B `cloud_hmac` | 云端 + 本店总控 | 总控拉授权 / 回执 / 人脸 / 打印；请求须带 `X-Lobn-Store-Id` |
| C `cctv_enroll_hmac` | 监控 + 总控 | 总控 → 监控人脸入库 |

多店：每店部署一份 SmartCenter（可选 SmartCCTV）。HA 配置填本店 `store_id` / `room_id` 与该店 HMAC（门店档案可写店级密钥，空则用云端全局 `hmac_cloud_secret`）。两店不可共用同一 pending 拉取身份。

管理后台：配置 `admin_phones`；店长/运维在「店员角色」按手机号许可；生产用小程序「店员登录」扫码（仅未绑定时取手机号）。

学员 JWT 与店员角色 JWT 不混用。

## 云端零入站

办公室总控主动 HTTPS 访问云端；不对办公室开入站端口。

- 公网：`https://fireclassroom.aleedu.com`（Caddy：`LOBN_FireClassroom/deploy/Caddyfile.public`）
- 总控 `cloud_base_url`：同上；`cloud_hmac_secret` 与本店密钥一致，并配置 `store_id`
- 内网名：`smartcenter.lobn` / `cctv.lobn` / `fireclassroom.lobn`（`Caddyfile.lan`）
