# 部署与密钥

终态：[架构-HAOS四App.md](架构-HAOS四App.md)。自研 CCTV：[决策-归档自研SmartCCTV.md](决策-归档自研SmartCCTV.md)。

## 店内部署要点

| 项 | 做法 |
|----|------|
| 主机 | HAOS（如 N100 + USB Coral） |
| App | HA、Mosquitto、Frigate Full Access、analytics-sidecar |
| 集成 | HACS Frigate Integration；MQTT 集成 |
| 摄像头 | 只被 Frigate/go2rtc 拉流（≤2 连接） |
| 门禁 | ESPHome → MQTT `home/*/command|state` |
| 云端 | VPS 上 LOBN_FireClassroom；店主动出站 |

## 现行密钥

| 密钥 | 持有方 | 用途 |
|------|--------|------|
| B `cloud_hmac` | 云端 + 店（sidecar/桥接/过渡期 lobn_office） | 授权/人脸流程/告警/报表；`X-Lobn-Store-Id` |
| MQTT | Mosquitto ACL / 用户 | 总线；生产应限制匿名 |
| 云存储（取证） | sidecar rclone | 导出加密上传 |

多店：每店一台 HAOS；`school_id` / `store_id` 隔离。两店不可共用同一云端 pending 拉取身份。

学员 JWT 与店员 JWT 不混用。管理后台 `admin_phones` 等仍见云端配置。
