## 店内部署要点

| 项 | 做法 |
|----|------|
| 主机 | HAOS（如 N100 + USB Coral） |
| App | HA、Mosquitto、Frigate Full Access、**SmartCenter Add-on** |
| 集成 | HACS Frigate Integration；MQTT；可选 Advanced Camera Card |
| 摄像头 | 只被 Frigate/go2rtc 拉流（≤2 连接）；**关 Face Recognition** |
| 门禁 | ESPHome → MQTT `home/<node>/door/command\|state` |
| 刷脸 | Add-on 发 `business/access/grant` → HA `face_grant_mqtt` → 门脉冲 |
| 云端 | VPS 上 LOBN_FireClassroom；店主动出站；人脸帧只中继 |

## 现行密钥

| 密钥 | 持有方 | 用途 |
|------|--------|------|
| B `cloud_hmac` / `LOBN_HMAC_CLOUD_SECRET` | 云端 + 店（Add-on / 过渡期 lobn_office） | 授权、状态同步、告警；`X-Lobn-Store-Id` |
| Add-on 中继 `cloud_hmac_secret` ≈ `LOBN_SMARTCENTER_RELAY_TOKEN` | 云端 ↔ Add-on | 人脸会话帧中继与 `face_status` 回写 |
| MQTT 用户/ACL | Mosquitto | 总线；**仅 Add-on 账号可发** `business/access/grant` |
| ESPHome `api_encryption_key` | 各节点 `secrets.yaml` | HA API 加密（32 字节 base64） |

多店：每店一台 HAOS；`school_id` / `store_id` 隔离。两店不可共用同一云端 pending 拉取身份。

学员 JWT 与店员 JWT 不混用。管理后台 `admin_phones`（平台管理员，与门店无关）、`admin_console_enabled`、时段窗等见云端 [LOBN_FireClassroom/docs/配置说明.md](../LOBN_FireClassroom/docs/配置说明.md) · [角色与控制台.md](../LOBN_FireClassroom/docs/角色与控制台.md)。
