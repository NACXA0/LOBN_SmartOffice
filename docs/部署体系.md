# 店内部署体系（HA · Frigate · 硬件 · SmartOffice）

> 现行架构：[架构-HAOS四App.md](架构-HAOS四App.md) · 人脸：[SmartOffice.md](SmartOffice.md) · 密钥：[部署与密钥.md](部署与密钥.md)  
> **已有 HAOS / Frigate 在跑？** → 先看 [对接已有HAOS.md](对接已有HAOS.md)，不必重装系统。  
> **本机日常开发（热更）** → [开发工作流.md](开发工作流.md)。  
> 目标：一台 **HAOS** 主机装齐四 App，摄像头只进 Frigate，门/RFID 走 ESPHome，刷脸决策在 **SmartOffice**，云端只做交易与会话中继。

## 0. 总览

| 层 | 组件 | 仓内落点 | 职责 |
|----|------|----------|------|
| 主机 | HAOS（N100 等 + USB Coral） | — | Supervisor 安装/备份/升级 |
| ① | Home Assistant Core | `config/` | 实体、保命自动化、Ingress、侧边栏 |
| ② | Mosquitto | Supervisor App | 唯一 MQTT 总线 |
| ③ | Frigate Full Access | `docs/examples/frigate.config.*.yml` | 拉流、检测、录像；**关 Face Recognition** |
| ④ | SmartOffice | `addon/` | 人脸工作台 + 底库 + 门口比对 → `business/access/grant` |
| 集成 | HACS Frigate Integration + Advanced Camera Card | HA | 实体翻译、仪表盘卡片 |
| 硬件 | ESP32 教室总控 | `firmware/esphome/` | 门脉冲、RFID、DHT、警号 |
| 云端 | LOBN_FireClassroom | `LOBN_FireClassroom/` | 小程序、预约支付、人脸帧**中继**（不落长期照片） |

实施顺序（与架构 §六一致）：

1. **底座**：Mosquitto + Frigate + MQTT `frigate/events` → [阶段1-HAOS底座验收.md](阶段1-HAOS底座验收.md)  
2. **执行层**：ESPHome 门 + HA `door_mqtt` / RFID  
3. **智能层**：SmartOffice + `face_grant_mqtt`  
4. **扩展**：利用率看板、取证上传（不阻塞刷脸上线）

## 1. 主机与网络

### 1.1 硬件清单

| 项 | 要求 |
|----|------|
| 主机 | 建议 Intel N100 级小主机，刷 **HAOS**（非仅 Container） |
| Coral | USB Coral TPU（Frigate Full Access 检测加速）；可先无 Coral 用 CPU 跑通事件 |
| 盘 | 系统盘 + 录像数据盘（保留天数如 30） |
| 网 | 与摄像头、ESP、办公 Wi‑Fi 同网段或可路由；**不对公网开放**监控/MQTT 端口 |
| 摄像头 | 支持 RTSP；每路只被 Frigate/go2rtc 拉（连接数 ≤2） |
| 门控板 | ESP32（推荐 S3）+ 继电器/门磁；可选 RFID 读头（RS485 或 Wiegand） |

### 1.2 网络名（约定）

| 用途 | 地址 |
|------|------|
| 公网 API / 管理端 | `https://fireclassroom.aleedu.com` |
| HAOS | 内网 IP 或 mDNS；Supervisor 内常用 `homeassistant` |
| Mosquitto | `core-mosquitto:1883` |
| Frigate API | Supervisor slug，常见形如 `ccab4aaf-frigate-fa:5000`；go2rtc `:1984` |
| SmartOffice | Ingress（HA 侧边栏）或映射 `:8080` |
| 云端 → 店 | **店主动出站**连云；云端不入站扫监控 |

多店：每店一台 HAOS；`school_id` / `store_id` 隔离。

## 2. Home Assistant（①）

### 2.1 配置目录

生产：把本仓 `config/` 同步到 HAOS 配置目录（或 git pull / Supervisor 备份恢复）。

关键文件：

| 文件 | 作用 |
|------|------|
| `configuration.yaml` | 包引用、默认语言等 |
| `packages/door_mqtt.yaml` | 店员 `input_button` → `home/<node>/door/command` |
| `packages/face_grant_mqtt.yaml` | 订 `business/access/grant` → 门脉冲（过期/重复 `command_id` 拒） |
| `packages/rfid_asset_guard.yaml` | RFID 白名单 retained + 未授权通知 |
| `custom_components/lobn_office/` | 过渡期云端开门队列 / 适配器（`mqtt`） |

`configuration.yaml` 中应包含：

```yaml
homeassistant:
  packages:
    rfid_asset_guard: !include packages/rfid_asset_guard.yaml
    door_mqtt: !include packages/door_mqtt.yaml
    face_grant_mqtt: !include packages/face_grant_mqtt.yaml
```

### 2.2 必装集成

| 集成 | 用途 |
|------|------|
| **MQTT** | 连 Mosquitto；发现实体、发 command |
| **HACS → Frigate** | Frigate 相机/事件实体 |
| **Advanced Camera Card**（可选） | Lovelace 实时预览卡片 |
| **ESPHome** | 发现教室总控节点 |

### 2.3 侧边栏

- iframe → Frigate UI（预览/录像）  
- iframe / Ingress → **SmartOffice**（总览 / 人员 / 审计；无自建登录）

### 2.4 保命纪律

- HA 自动化**零智能**：不做排班 SQL、不做相似度比对  
- 刷脸开门只翻译：`business/access/grant` → `home/<node>/door/command`  
- 店员手动开门不经云端、不经 Add-on  

开发机：仓库根 `./START.sh` 可起本机 HA，**不能替代**店内 Frigate/Coral。

## 3. Mosquitto（②）

Supervisor → 安装 **Mosquitto broker**。

建议：

1. 关闭匿名；建至少三组用户（生产 ACL）：  
   - `frigate`：可发 `frigate/#`，只读业务主题按需  
   - `smartcenter`：**唯一**可发 `business/access/grant`；订 `frigate/#`  
   - `homeassistant` / `esphome`：`home/#` 读写按节点划分  
2. HA MQTT 集成、Frigate `mqtt:`、Add-on `mqtt_*`、ESPHome `mqtt:` 全部指向 `core-mosquitto`  
3. 验收：`mosquitto_sub -t 'frigate/#' -v` 有人走过能看到 `frigate/events`

密钥表见 [部署与密钥.md](部署与密钥.md)。

## 4. Frigate Full Access（③）

### 4.1 安装

Supervisor → **Frigate Full Access**（需设备权限挂 Coral、`/dev/bus/usb`、录像盘）。

挂载：

- 配置目录 → `config.yml`  
- `/media` 或专用盘 → 录像与 exports  
- Coral USB  

### 4.2 配置原则

样例：[examples/frigate.config.phase1.example.yml](examples/frigate.config.phase1.example.yml)（阶段①）  
刷脸阶段样例：[examples/frigate.config.face-door.example.yml](examples/frigate.config.face-door.example.yml)

必须：

| 项 | 要求 |
|----|------|
| `mqtt.host` | `core-mosquitto` + 专用用户 |
| `go2rtc.streams` | 每路摄像头唯一消费点 |
| `cameras.*.zones` | 门口 zone 名与 Add-on `door_zones` 一致（如 `front_desk_zone`） |
| `objects.track` | 至少 `person` |
| **Face Recognition** | **`enabled: false`**（身份在 Add-on） |
| 业务规则 | **禁止**在 `config.yml` 写开门/排班 |

门口相机名（如 `front_desk`）须与 Add-on `door_cameras`、go2rtc stream 名一致。

### 4.3 验收

见 [阶段1-HAOS底座验收.md](阶段1-HAOS底座验收.md)：预览、录像、MQTT `frigate/events`、Integration 实体。

## 5. SmartOffice（④）

### 5.1 安装

仓内：`addon/`（仓库根有 [repository.yaml](../repository.yaml)；本地 Add-on 仓库或复制到 `/addons`）。  
`Dockerfile` 多阶段构建 `web/` → `app/webui`。

`config.yaml` 要点：`ingress: true`、`hassio_api: true`、`mqtt:need`。

选项（与 Frigate / 云端对齐）：

| 选项 | 说明 |
|------|------|
| `door_cameras` / `door_zones` | 与 Frigate 门口机位、zone 同名 |
| `door_node` | ESPHome `room_id`，如 `front_gate` |
| `match_threshold` / `verify_threshold` | 开门线 / 机会式验证线 |
| `cooldown_sec` | 同人冷却（默认 30） |
| `frigate_url` / `go2rtc_url` | Supervisor 内网名 |
| `cloud_base_url` / `cloud_hmac_secret` | 回写 `face_status`、学员搜索、与云端中继 token 一致 |
| `model_version` / `embedder` | 生产用 ONNX；开发可用 `mock` |
| `audit_max_rows` / `audit_max_age_days` | 审计表容量（默认 5000 / 30 天） |
| `log_max_mb` / `log_backup_count` | 滚动日志（默认 5×5MB） |
| `session_ttl_sec` / `maintenance_interval_sec` | 会话超时与维护周期 |
| `match_concurrency` | 门口比对并发（默认 1，忙则丢） |
| `backup_interval_hours` | 在线备份间隔（默认 6h，保留 10 份） |

数据卷 `/data`：SQLite 底库 + 合格采集帧 + 滚动日志 + 在线备份。**丢卷 = 全员重采**；备份是上线项。

Ingress 工作台（HA 已登录即可，**无 Add-on 登录页**）：

| 页 | 用途 |
|----|------|
| 概览 | 库规模、开门统计、待重采 |
| 采集 | 搜索选人 + 自动质检 |
| 人员 | 启停 / 删 / 改名 / 档案内采集 / 合格帧 |
| 审计 | 流水 + MQTT/模型/磁盘 |

### 5.2 本地开发（推荐本机 · 热更新）

比「本机 Add-on → 内网 HAOS」更方便：无防火墙/ACL、不误伤生产。专文：[开发工作流.md](开发工作流.md)。

```bash
# 在仓库根
./START.sh repair --yes && ./START.sh addon-repair
./START.sh all    # Vite :5173（HMR）+ API :8080（reload）+ 本机 HA :8123
```

发版前：`./START.sh addon-ui-build` · `./START.sh addon-test`。  
店内 HAOS：生产安装与终验，见 [对接已有HAOS.md](对接已有HAOS.md)。

### 5.3 HA 侧联动（店内）

1. 安装 Add-on 后侧边栏出现 **SmartCenter** Ingress  
2. 确认 `packages/face_grant_mqtt.yaml` 已加载  
3. 工作人员用 HA 管理员打开 Ingress → USB/`getUserMedia` 采集  
4. 学生走小程序 → 云端 `/api/face/session/*` → Add-on（店主动出站）

说明：`addon/README.md`、[SmartOffice.md](SmartOffice.md)

### 5.4 刷脸链路验收

1. 门口 zone 有人 → Frigate 发 `frigate/events`  
2. Add-on 审计 / `/api/stats` 有记录  
3. MQTT 出现 `business/access/grant`（含 `command_id`、`expires_at`）  
4. HA 发 `home/front_gate/door/command` → 门开  
5. 重复同一 `command_id` / 过期 grant **不**再脉冲  
6. 停用 Add-on：店员 `input_button` 仍可开；刷脸停  
7. Ingress 四页可开；`/healthz`、`/data/logs` 滚动正常

## 6. 硬件（ESPHome 教室总控）

### 6.1 固件

路径：`firmware/esphome/`  
**不要**部署遗留 `firmware/esp32s3_door/` HTTP 门协议。

```bash
cd firmware/esphome
./START.sh                 # 推荐 Device Builder :6052
# 或从仓库根：./START.sh flash
```

编辑：

| 文件 | 内容 |
|------|------|
| `classroom_node.yaml` | `substitutions.room_id`：大门 `front_gate`、教室 `classroom_1` |
| `secrets.yaml` | Wi‑Fi、MQTT、`api_encryption_key`（`openssl rand -base64 32`） |
| `packages/door.yaml` | 订 `home/<room_id>/door/command`，报 `…/door/state` |
| `packages/rfid_*.yaml` | 通道防盗（可选） |
| `packages/climate_dht11.yaml` / `siren.yaml` | 温湿度、警号 |

每门一颗板；`room_id` 必须与 HA 主题、`face_grant` 的 `node`、Add-on `door_node` 一致。

### 6.2 接线要点（逻辑）

| 功能 | 说明 |
|------|------|
| 门锁继电器 | 仅听 MQTT command 脉冲；并联物理钥匙/按钮 |
| 门磁 | 上报 `open`/`closed` |
| RFID | 本地比对 HA retained 白名单；断网仍按最后名单报警 |
| DHT | 可选环境传感 |

RFID 专文：[资产防盗-RFID.md](资产防盗-RFID.md)。  
HA 包：`packages/rfid_asset_guard.yaml`。

### 6.3 硬件验收

- [ ] HA `input_button` 大门/里门 → 对应节点脉冲  
- [ ] grant 链路开门（阶段③后）  
- [ ] 门磁实体正确  
- [ ]（若启用）未授权 RFID → 警号 + `home/<room>/rfid/event`

## 7. 云端（LOBN_FireClassroom）

### 7.1 部署

VPS + Caddy：见 `LOBN_FireClassroom/deploy/`、`./START.sh`。  
公网只暴露 API / 管理端 / 小程序后端；**不**暴露店内 MQTT/Frigate。

### 7.2 与店内人脸相关的环境变量

| 变量 | 说明 |
|------|------|
| `LOBN_SMARTCENTER_BASE_URL` | 店主动可达的 Add-on 基址（出站中继） |
| `LOBN_SMARTCENTER_RELAY_TOKEN` | 与 Add-on `cloud_hmac_secret` 一致；空则回落 `LOBN_HMAC_CLOUD_SECRET` |
| `LOBN_HMAC_CLOUD_SECRET` | 云店 HMAC B |

小程序采集页：`packageUser/faceEnroll` → `/api/face/session/*`（帧不落库）。

生产 `is_prod=true`；支付见 `LOBN_FireClassroom/docs/payment-runbook.md`。  
管理端平台/门店控制台与启动：`LOBN_FireClassroom/docs/README.md`。

## 8. 备份与故障域

| 层 | 挂了 | 备份 |
|----|------|------|
| HA + 保命自动化 + ESP | 软件开门停；钥匙仍可用 | Supervisor 快照；ESPHome 仓 |
| Frigate | 刷脸停；手动门仍可 | `config.yml` + 录像盘 |
| SmartOffice | 刷脸停；保命不受影响 | `/data` SQLite 在线备份 + 合格帧 |
| 云端 | 新预约/中继采集受影响；已 `accepted` 本地仍可开（停用以云端为准） | VPS 备份 |

Supervisor 快照应覆盖：HA 配置、Mosquitto、Frigate、Add-on 选项与数据盘策略。
